# Setup
---
1. Clone the repository
```{r}
git clone <repo-url>
cd <repo-folder>
```

2. Create and activate a virtual environment 
```{r}
# Create
python -m venv .venv

# Activate (macOS/Linux)
source venv/bin/activate

# Activate (Windows)
venv\Scripts\activate
```
3. Install dependencies
```{r}
pip install -r requirements.txt
```
